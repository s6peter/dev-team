# Evidence

This folder is for SOC 2 and internal audit evidence guidance, not for dumping random screenshots.

Use this area for:

- evidence collection instructions
- control-to-artifact mappings
- export checklists
- screenshot naming standards
- review cadence documentation

Evidence should be:

- date-stamped
- linked to a control objective
- attributable to an owner
- reproducible when possible
- stored without secrets

Primary evidence themes for this program:

- logging and retention
- monitoring and response
- access control
- change management
