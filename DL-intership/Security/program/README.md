# Program

This folder should hold the program-level artifacts that explain why the work exists and what comes next.

Keep items here such as:

- roadmap and milestone plans
- security architecture decisions
- sprint plans for major security initiatives
- approved exceptions and follow-up actions
- summarized findings from current-state reviews

Current program direction from the reviewed source materials:

1. protect CloudTrail and the log archive first
2. deploy OpenSearch and stable ingestion next
3. operationalize detections, routing, and runbooks
4. build recurring evidence for SOC 2 readiness
